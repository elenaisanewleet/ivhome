ФИНАЛЬНАЯ РЕКОМЕНДАЦИЯ
Variant A / Canonical — production default. v1 color system + v1 service card visual + v2 typography (Unbounded/Onest) + v2 icon quality + PNG flow logic.

Variant B — интересная альтернатива, но в Telegram Mini App теряет clarity primary action и не даёт значимого преимущества над A.
