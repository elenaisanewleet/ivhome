Надом
design package · v6.2 · telegram mini app · bot · dashboard · web

Анонимный сервис подбора клиники, медслужбы или выездной бригады на дом в Москве. Для подбора не нужны паспорт и точный адрес — адрес понадобится только после выбора клиники и увидит его лишь она.

Надом — не клиника и не скорая помощь. Возможность выезда, формат помощи, состав услуги и финальную стоимость подтверждает выбранная клиника или медслужба.

Единый источник правды для дизайна Mini App, бота, дашборда и сайта. Главное в v6: первичный знак — пакет-капельница; тёплый графит с кремовыми экранами; мягкий синий как основной акцент; флагман — раскрытая карточка клиники. Слоган: Быстро. Удобно. Анонимно.

Этот файл — спецификация, а не приложение. Реализация — строго по разделу 24 (CodeX) и словарю формулировок (раздел 25).
02 — Brand concept

Брендовая идея

Надом звучит как приватный технологичный помощник — не клиника, не доктор-бот, не наркологический лендинг. Спокойно, по-человечески, по-телеграмному.

Что это

Агрегатор / matching-сервис. Пользователь выбирает медслужбу, пишет специалисту, уточняет условия и подтверждает заявку. Надом не оказывает медицинских услуг.

Характер

Приватный · технологичный · дорогой · спокойный · Telegram-native. Тёмный-first. Минимум данных на старте. Без давления, стыда и паники.

Знак v6

Пакет-капельница — первичный символ везде. Абстрактная капля — только декоративный мотив. Маршруты, узлы и сигналы из бренд-контекста убраны.

Звучит так

  • подбор медслужбы с выездом на дом
  • анонимно на этапе подбора
  • без лишних звонков
  • детали подтверждает выбранная клиника
  • спокойно, коротко, по-человечески

Никогда

  • клиника Надом · врач Надом · наш врач
  • лечим · диагностируем · назначаем
  • гарантируем результат · подберём капельницу
  • полная анонимность как абсолют
  • агрессивные баннеры, стыд, паника, сирены

БлокЧто
AИдентичность: название · лицензия/верификация · яркий рейтинг «4.8 ★ · 126 отзывов» · зона «Москва · выезд по районам» · «доступна сейчас / 24/7» · «Детали подтверждает медслужба»

CРейтинг: янтарный, тёплый — виден в короткой и раскрытой карточке.
DКаталог: ровно 5 фиксированных услуг с иконкой/акцентом/названием/описанием/ценой/состоянием выбора.
EОписать ситуацию — отдельная панель под 5 услугами. Не шестая платная строка. «Не нашли подходящий вариант?» + 2 кнопки.
FЦена/условия: ориентир · что уточняет медслужба · что влияет на цену · финальная стоимость после подтверждения.
GДоверие: чипы лицензии/24-7/анонимности/без звонков/паспорта/адреса + безопасная формулировка.
HЧат: заметный блок «Написать специалисту» + хелпер.
IДействия: primary «Выбрать услугу», teal «Написать специалисту», «Описать свою ситуацию», «Сравнить», ghost «Назад», маленькая «103/112».

20 — Diagnostics

Диагностика · без секретов

Карточки диагностики не показывают значения токенов и заголовки Authorization. Только маршрут, код и нейтральное сообщение.

disabled/mvp/dev/requests
Dev-API выключен в production. Включается флагом ENABLE_MVP_DEV_API только в превью.
401 / 403/mvp/admin/requests
Нет доступа. Проверьте admin-токен в sessionStorage. Значение токена не отображается.
500 / 503/mvp/admin/requests
Сервис недоступен. Повтор безопасен. Сообщение без чувствительных деталей.
401 / 403/mvp/admin/clinics
Нет доступа к списку медслужб. Ограничьте доступ на уровне платформы.
fetch / CORSVITE_API_BASE_URL
Ошибка соединения или CORS. Проверьте API URL и список CORS_ORIGINS.
health/health/ready
Process-level health OK. Подключение к БД проверяется отдельно.
Безопасность: диагностика никогда не показывает значения токенов и заголовки Authorization. Логи — без чувствительных данных.
