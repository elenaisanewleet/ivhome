02 — Палитры
3 направления, 1 выбор
Предлагаю три цветовые системы. Выбор — направление A.
A · Void — Signal — Sage
ВЫБРАНО ✓
Почти чёрный оливковый фон + стальной синий акцент + сажевый зелёный как второй акцент для подтверждений. Ember — только для экстренных кнопок. Технологично, закрыто, взрослое. Не больничное. Не wellness.
B · Midnight Copper
Глубокий синевато-чёрный + медный акцент + дымчатый чирок. Более тёплый, дорогой, но рискует уйти в luxury-wellness. Меньше читается как tech.
C · Graphite Mineral
Чистый графит + минеральный зелёный + шиферный синий. Лаконично, но слишком нейтрально — ощущение утилиты, не технологичного сервиса.

Капля — форма, которая возникает сама: тянется вниз, к точке назначения. Не медицинская капля, не капельница в лоб — маршрут движения, вектор прибытия.

Центральный круг — точка соединения: пользователь нашёл медслужбу.

Пунктирная дуга снизу — след прибытия, движение специалиста к адресу. Тонкая, ненавязчивая.

Намёк на капельницу считывается со второго взгляда (вертикальная ось + точка).

Не дом. Не крест. Не пульс. Не молекула. Не "Н".
