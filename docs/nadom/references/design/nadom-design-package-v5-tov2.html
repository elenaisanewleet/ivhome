Быстро. Удобно. Анонимно.
Надом — приватный технологический сервис подбора медслужбы с выездом на дом в Москве. Агрегатор и сервис мэтчинга, не клиника. Не оказывает медицинских услуг, не ставит диагнозы. Стоимость, состав, ETA и итоговые условия подтверждает выбранная медслужба.

v5: электрический петроль вместо Telegram-синего, семантические цвета иконок, 10 состояний бота с реальной механикой, тёмная тема — первична.

Единый источник правды для Mini App · Bot · Dashboard · Web. Каждый раздел — рабочая спецификация. Цвет несёт значение: навигация, статус, безопасность, приоритет действия.

Реализация — строго по разделам 30 (CodeX), 31 (Словарь), 32 (Export). Этот файл не меняет приложение — только дизайн-систему.
02 — Final brand concept

Брендовая идея

Анонимный подбор клиники с выездом на дом. Быстро. Удобно. Анонимно. Пакет-капельница — фирменный знак Надома.

Пакет-капельница — ОСНОВНОЙ символ

Пакет с раствором + заполненная капля — фирменный знак Надома. Аватар бота, splash, hero, фавикон. Однозначно читается как медицинская выездная помощь.

Слоган: «Быстро. Удобно. Анонимно.»

Иерархия знаков
0
Пакет-капельница — первичный. Идентичность бренда везде.
A
Абстрактная IV — декоративный мотив. Фон, паттерн, motion. Не логотип.
B
Relay glyph — функциональная UI-иконка. Не элемент бренда.
Главное слово бренда — «анонимно». Слоган: Быстро. Удобно. Анонимно.
Суть

Надом соединяет человека в неудобной ситуации с лицензированной медслужбой. Бренд — «узел связи» (реле) + спокойный маршрут. Не паника, не реклама — приватный сервис подбора.

Тон

Сдержанный, конкретный, без обещаний. Каждый экран — одно решение. UI понятен за 2–3 секунды стрессующему или уставшему человеку.

Цвет v5

Электрический петроль #0C7A8C вместо Telegram-синего. Teal #1A9080 — действие специалиста. Ink/paper — база. Каждый семантический цвет несёт значение, не декор.
