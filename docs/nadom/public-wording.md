# Nadom public wording rules

## Brand boundary

Use Nadom / Надом as the public user-facing brand in UI, Telegram Bot copy, Mini App copy, landing pages, user-facing documentation, and promotion. IVhome is an internal repository and project name only; it may remain in technical contexts, package names, migrations, and admin or developer documentation.

## Allowed public terms

Prefer these terms:

* `медицинский выезд на дом`
* `медицинская организация`
* `организация с выездом на дом`
* `выбранная организация`
* `медицинский специалист`
* `специалист выбранной организации`
* `выездная бригада`
* `подходящий вариант`
* `предложение`
* `конфиденциальный подбор`
* `детали подтверждает выбранная организация`
* `стоимость после подтверждения`
* `при экстренных симптомах обратитесь в 103/112`
* `сервис не заменяет очную консультацию`
* `ожидаемое время прибытия`

Do not use `служба` as the default public term. Prefer `медицинская организация`, `выбранная организация`, `специалист выбранной организации`, `медицинский специалист`, `выездная бригада`, `предложение`, or `вариант` as appropriate.

`Партнёр` is allowed only in internal documentation, code, admin tools, or PR descriptions. It must not be the main public UI term.

Use `врач` or `доктор` only if the selected organization has actually confirmed that the specialist is a doctor. Never imply that a doctor belongs to Nadom.

## Forbidden public wording

Do not use:

* `анонимная капельница`
* `полная анонимность`
* `анонимно` as an absolute promise
* `лечим`
* `назначаем`
* `диагностируем`
* `гарантируем лечение`
* `капельница решит проблему`
* `безопасно всем`
* `врач IVhome`
* `врач Надом`
* `наш врач`
* `наш партнёр`
* `лучшая клиника`
* urgency or FOMO phrases such as `срочно`, `успейте`, or `осталось мало мест`
* `наркол`
* `доктор бот`
* `инкогнито`
* `тайно`
* `анонимка`

Do not make medical claims or absolute anonymity claims.

## Tone of voice

Public copy is in Russian. Keep it short, calm, soft, and Telegram-native. Avoid bureaucracy, shame, fear-based pressure, medical drama, and sales aggression. Use one semantic block at a time. Prefer buttons and short lines over long paragraphs.

Use soft symbols sparingly:

* 🫧 for greeting and onboarding;
* 🪽 for visit, confirmation, or movement;
* 🩵 for support and final state;
* 🧊 for waiting and pause;
* ⋆ / ✦ / ⊹ for list markers.

Do not use emoji in hard-stop or legally sensitive messages.

## Good UI copy examples

* `привет, я Надом 🫧`
* `если нужен медицинский выезд на дом — помогу найти подходящий вариант`
* `детали подтверждает выбранная организация`
* `при экстренных симптомах обратитесь в 103/112`

## Hard-stop copy

Use this copy without emoji:

`при таких симптомах выезд на дом может быть небезопасен. пожалуйста, обратитесь за экстренной помощью: 103 или 112`
