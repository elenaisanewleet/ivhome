# @nadom_bot — что писать и куда (пошагово)

Делай сверху вниз. Слева — куда нажать, справа — что вписать/загрузить.
Все тексты можно копировать как есть.

---

## Часть 1 · BotFather (настройка бота)

Открой [@BotFather](https://t.me/BotFather) в Telegram и отправляй команды по очереди.

### 1. Имя бота
Отправь: `/setname` → выбери бота → впиши:
```
Надом
```

### 2. Описание (большой текст перед кнопкой «Запустить»)
Отправь: `/setdescription` → выбери бота → вставь:
```
Надом показывает, кто приедет, когда и за сколько — вы выбираете медслужбу для выезда на дом, остальное берём на себя.

Экстренно или планово. Анонимно, без лишних звонков.

При острых симптомах — 103 или 112.
```

### 3. Краткое «О боте» (в профиле)
Отправь: `/setabouttext` → выбери бота → вставь:
```
Кто приедет, когда и за сколько — выезд медслужбы на дом в Москве
```

### 4. Аватар бота
Отправь: `/setuserpic` → выбери бота → **загрузи PNG** (см. Часть 4, какой выбрать).

### 5. Команды (меню по кнопке «/»)
Отправь: `/setcommands` → выбери бота → вставь обе строки разом:
```
start - начать
help - помощь
```

### 6. Приватность (бот видит только команды)
Отправь: `/setprivacy` → выбери бота → выбери **Enable**.

### 7. Кнопка-меню, открывающая Mini App
Отправь: `/setmenubutton` → выбери бота →
- тип: **Web App**
- текст кнопки: `Надом`
- URL: адрес твоего Mini App (например `https://nadom.app`)

### 8. Домен Mini App
Отправь: `/setdomain` → выбери бота → впиши домен Mini App (тот же, что в шаге 7).

### 9. Картинка приветствия (показывается до «Запустить»)
`/mybots` → выбери бота → **Bot Settings → Welcome Message → Set Welcome Picture** →
загрузи:
- **анимированный GIF** `anim/welcome-640x360.gif` (выглядит как стикер ✨), **или**
- статичный PNG `png/welcome-640x360.png`

### 10. Splash-иконка Mini App (экран загрузки приложения)
`/mybots` → выбери бота → **Bot Settings → Mini App / Web App → Launch Screen → Set Splash Icon** →
загрузи `splash-icon.svg`.
Там же выставь **Background color** и **Header color** (рекомендация: фон `#F2F1EB` для светлой, `#17212B` для тёмной).

## Часть 2 · Кнопки бота (уже в коде, ничего вписывать не надо)

Эти кнопки появляются автоматически — они зашиты в `apps/telegram-bot`:

| Где | Кнопка | Что делает |
|---|---|---|
| Ответ на `/start` | **подобрать вариант** | открывает Mini App |
| Ответ на `/help` | **открыть Надом** | открывает Mini App |
| Любое другое сообщение | **открыть Надом** | мягко возвращает в приложение |
| Уведомление о статусе | **открыть Надом** | открывает Mini App на нужном экране |

Нужно только задать боту две переменные окружения (Часть 3).

---

## Часть 3 · Переменные окружения (для запуска бота)

В `.env` (локально) и в настройках хостинга (Render):
```
TELEGRAM_BOT_TOKEN=<токен от BotFather>
TELEGRAM_WEBAPP_URL=<адрес Mini App, например https://nadom.app>
```
Токен НЕ коммить в git. Без `TELEGRAM_WEBAPP_URL` кнопки не появятся (бот предупредит в логе).

## Часть 4 · Какие файлы куда

| Что настраиваешь | Файл | Формат |
|---|---|---|
| Аватар бота (шаг 4) | один из `png/av-*.png` | PNG 512×512 |
| Картинка приветствия (шаг 9) | `anim/welcome-640x360.gif` или `png/welcome-640x360.png` | GIF / PNG 640×360 |
| Splash Mini App (шаг 10) | `splash-icon.svg` | SVG, один `<path>` |

**Выбор аватара** — открой `png/preview-avatars3.png` (капельницы) и `png/preview-avatars2.png`
(дом+метка, метка). Скажи, какой — поставлю как основной `avatar.png`.

## Готово ✓

После шагов 1–10 и переменных окружения бот:
1. отвечает на `/start` и `/help` с кнопкой в Mini App,
2. показывает анимированное приветствие и красивый splash,
3. шлёт уведомления о статусе без лишних деталей.
