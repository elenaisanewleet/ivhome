# @nadom_bot — Тексты v2 (с HTML-форматированием)

Новая редакция текстов в духе «тихого диспетчера».
`parse_mode: "HTML"` — Telegram поддерживает без Markdown-конфликтов.

---

## /start

```
привет 🫧

нужен медицинский выезд на дом — помогу найти вариант

<i>детали, стоимость и медицинскую возможность подтверждает выбранная медслужба</i>
```

**Inline-кнопка:**
```
подобрать вариант  →  web_app
```

## Экстренный слой (встроен в онбординг Mini App)

Этот текст — в Mini App, не в боте. Но тон — тот же:

```
при таких симптомах выезд на дом
может быть небезопасен

лучше позвоните 103 или 112
```

Без заглавных. Без "ВНИМАНИЕ". Без эмодзи.

## Быстрый глоссарий для редактора

| Понятие | Как пишем |
|---|---|
| Медицинская организация | медслужба (коротко в UI) |
| Специалист партнёра | специалист выбранной медслужбы |
| Подтверждение заявки | взяли в работу |
| Стоимость визита | стоимость (не "цена", не "прайс") |
| Ответ медслужбы | ответ (не "реакция", не "отклик") |
| Время прибытия | прибытие (не "ETA", не "доставка") |
| Отмена | отменить (не "удалить заявку") |
