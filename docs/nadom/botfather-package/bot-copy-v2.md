# @nadom_bot — Тексты ответов бота

Каноничная редакция. `parse_mode: "HTML"`. Терминология: только **медслужба**,
для доверия — **проверенная медслужба**. Бренд-слова: **анонимно · быстро · удобно**.

Эти тексты совпадают с кодом бота (`apps/telegram-bot/src/index.ts`).

---

## /start

```
привет, я Надом 🫧

покажу, кто приедет на дом, когда и за сколько — а вы выберете медслужбу

<i>детали и стоимость подтверждает выбранная медслужба</i>
```

**Inline-кнопка:** `подобрать вариант` → web_app

---

## /help

```
<b>что умею</b>

⋆ подобрать проверенную медслужбу для выезда — экстренно или планово
⋆ показать условия: когда ответят, когда приедут, стоимость
⋆ держать в курсе статуса заявки

<i>анонимно · без лишних звонков</i>
<i>при острых симптомах — 103 или 112</i>
```

**Inline-кнопка:** `открыть Надом` → web_app

Без медицинских деталей. Только факт + кнопка в приложение.

<i>детали в приложении</i>
```

```

```
специалист выехал

<i>время приезда — в приложении</i>
```
**Кнопка:** `открыть Надом`

### Визит завершён (`completed`)

```

**Кнопка:** `оценить`

```
**Кнопка:** `открыть Надом`

возвращает в приложение и не повторяет содержимое (приватность).

```
всё здесь 🫧
```
**Кнопка:** `открыть Надом`

## Реализация (совпадает с кодом)

```typescript
// parse_mode HTML — для <b>/<i>
await callTelegramApi("sendMessage", {
  chat_id: chatId,
  text: "привет, я Надом 🫧\n\nпомогу быстро найти медслужбу для выезда на дом — вместо долгих поисков и звонков\n\n<i>детали и стоимость подтверждает выбранная медслужба</i>",
  parse_mode: "HTML",
  reply_markup: {
    inline_keyboard: [[{ text: "подобрать вариант", web_app: { url: webAppUrl } }]],
  },
});

// уведомления — protect_content, чтобы статус не пересылали
await callTelegramApi("sendMessage", {
  chat_id: userId,
  text: "<b>заявка подтверждена</b>\n\nмедслужба взяла в работу · детали в приложении",
  parse_mode: "HTML",
  protect_content: true,
  reply_markup: {
    inline_keyboard: [[{ text: "открыть Надом", web_app: { url: webAppUrl } }]],
  },
});
```

## Глоссарий редактора

| Понятие | Как пишем (приоритет) | Не пишем |
|---|---|---|
| Поставщик услуги | **медслужба** | партнёр, наш врач, «служба» |
| Доверие / проверка | **проверенная** или **лицензированная медслужба** | — |
| Специалист | **специалист выбранной медслужбы** | наш врач, врач Надом |
| Приватность | **анонимно** / конфиденциально / приватно | — |
| Время до ответа | **когда ответят**, «ответят за ~15 мин» | SLA, отклик |
| Время до приезда | **когда приедут**, «приедут за ~40 мин» | ETA, прибытие по SLA |
| Стоимость | **стоимость** (подтвердит медслужба) | цена, прайс |
| Экстренное | **при острых симптомах — 103 или 112** | паника, ВНИМАНИЕ |

> **Медслужба** — основной термин. «Медицинская организация» и «лицензия» уместны
> в формальных и правовых контекстах (профиль, consent), где добавляют ясности.
