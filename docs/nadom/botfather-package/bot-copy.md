## /start

**Обработчик:** `isStartCommand()` → `createStartMessage()`

**Текст:**

```
привет, я Надом 🫧

если нужен медицинский выезд на дом — помогу найти подходящий вариант

детали подтверждает выбранная организация
```

**Inline-кнопка:**

| Текст кнопки | Тип | Значение |
|---|---|---|
| `подобрать вариант` | `web_app` | URL Mini App |

## Правила применения символов

| Символ | Когда использовать |
|---|---|
| 🫧 | Приветствие, онбординг, мягкие завершения |
| ⋆ | Маркер списка в /help и справочных сообщениях |

Без эмодзи в уведомлениях о статусе и в любых сообщениях, где упоминается 103/112.

## Запрещённые формулировки

| Нельзя | Почему |
|---|---|
| `наш врач` / `врач Надом` | Надом не клиника |
| `мы приедем` / `наши специалисты` | Специалисты выбранной организации, не Надом |
| `лечим`, `назначаем`, `диагностируем` | Медицинские обещания |
| `партнёр` в UI | Использовать `медслужба` |
| `IVhome` в публичных сообщениях | Только внутренний codename |
| Медицинские детали в уведомлениях | Утечка приватных данных |
