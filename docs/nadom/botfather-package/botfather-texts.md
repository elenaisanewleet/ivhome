# @nadom_bot — Тексты BotFather

Все поля для настройки через BotFather. Копировать точно, без лишних пробелов.

---

## /setname — Имя бота

```
Надом
```

Имя отображается в заголовке чата и результатах поиска Telegram.

---

## /setdescription — Описание (до 512 символов)

Показывается на первом экране перед нажатием Start.

```
Надом — агрегатор экстренных или плановых медицинских услуг с выездом на дом. Вместо долгих поисков и звонков.

Выбирайте медслужбу по району, времени и условиям — видно, когда ответят и когда приедут. Детали и стоимость подтверждает выбранная медслужба.

Анонимно · быстро · удобно.

При острых симптомах — 103 или 112.
```

Длина: ~310 символов. Остаётся запас до 512.

---

## /setabouttext — Краткое описание профиля (до 120 символов)

Отображается на странице профиля бота и в поиске.

```
Подбор выездной медпомощи в Москве · анонимно · без лишних звонков
```

Длина: 65 символов.

---

## /setcommands — Список команд (bot command menu)

Вводить через BotFather построчно:

```
start - начать
help - помощь
```

Два пункта для MVP. Пользователь видит их в меню команд (иконка `/` в строке ввода).

---

## /setprivacy — Режим приватности

Установить: **Enabled**

BotFather → `/setprivacy` → выбрать бота → `Disable` или `Enable` → выбрать `Enable`.

Бот получает только сообщения, начинающиеся с `/`. Не читает общий трафик чата.

---

## /setmenubutton — Кнопка меню (Mini App)

BotFather → `/setmenubutton` → выбрать бота → `Web App` →

```
Надом
```

URL: `[URL Mini App — заполнить перед публикацией]`

Кнопка будет отображаться слева от строки ввода вместо стандартного меню команд и открывать Mini App напрямую.

---

## /setuserpic — Аватар бота

Файл: `assets/avatar.svg` → экспортировать в PNG 512×512 перед загрузкой.

Telegram принимает JPG или PNG. Рекомендовано: PNG 512×512.

Инструкция по экспорту: открыть `assets/avatar.svg` в браузере (Chrome/Safari) или Figma, экспортировать как PNG 512×512.

---

## /setdomain — Домен Mini App (для Web App)

Указать домен развёрнутого Mini App:

```
[домен Mini App — заполнить перед публикацией]
```

Например: `nadom.app` или адрес Render-деплоя.

---

## /setinline — Inline-режим

Для MVP: **не включать**.
