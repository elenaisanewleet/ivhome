# Надом — ревизия воркфлоу (дизайн · интерактив · юзабилити)

Прошёл весь путь Mini App: `welcome → consent → 103/112 → профиль → район →
время → список → карточка → чат → подтверждение → ожидание → price-lock →
выезд → завершение → оценка → поддержка → empty/error`.

Терминология и приватность — в порядке (медслужба, Ответ/Прибытие,
«детали подтверждает медслужба», чат не уходит в уведомления).

Ниже — что уже улучшил в этом проходе и что предлагаю дальше.

---

## ✅ Сделано в этом проходе

### Интерактив (Telegram-native)
- Подключил **Telegram WebApp SDK** безопасно (`src/telegram.ts`, feature-detected — не ломает web/dev):
  - `ready()` + `expand()` при запуске — приложение сразу на весь экран;
  - синхронизация **темы Telegram** (light/dark) в CSS-переменные;
  - **HapticFeedback** на ключевых действиях: переход вперёд (`light`),
    назад (`soft`), успешная заявка (`success`), ошибка (`error`),
    экран 103/112 (`warning`).

### Анимации / ощущение
- Плавное **появление каждого экрана** (`screen-card--enter`, 0.32s, мягкая кривая),
  привязано к `key` экрана — переход чувствуется.
- Готовые CSS-лоадеры: `.nadom-dots` (пульсирующие точки) и `.nadom-pulse`
  (расходящееся кольцо для статусов «ожидание» / «специалист в пути»).
- Всё уважает **`prefers-reduced-motion`**.
- Анимированные ассеты для приложения и бота: `anim/welcome-640x360.gif`
  (welcome как стикер), `anim/drip-loading.svg`, `anim/loading-dots.svg`, `anim/pulse.svg`.

## 🔜 Предлагаю дальше (по приоритету)

### P1 — нативные кнопки Telegram
Заменить нижнюю основную кнопку экрана на **MainButton** Telegram (вне контента,
в chrome): «Продолжить» / «Отправить заявку» / «Открыть чат». И **BackButton**
вместо кастомной «Назад». Это самый заметный шаг к «настоящему» Mini App.
Не сделал сразу — требует аккуратной привязки к стейт-машине шагов, лучше отдельным PR.

### P2 — живые статусы заявки
На экранах «ожидание» и «выезд» показать `.nadom-pulse` рядом со статусом и
мягко анимировать трек прогресса. Сейчас трек статичный.

### P3 — лоадеры вместо текста «Отправляем…»
В pending-состояниях кнопок показывать `.nadom-dots` вместо/рядом с текстом —
выглядит живее, чем меняющаяся надпись.

### P4 — скелетоны списка медслужб
Пока список грузится — показывать 2–3 скелетон-карточки (мерцание), а не пустоту.

### P5 — микро-детали карточки
- лёгкий hover/press на карточке медслужбы;
- бейдж рейтинга с иконкой;
- «Ответ»/«Прибытие» с маленькими иконками (часы / маршрут) для скорости чтения.

### P6 — пустые/ошибочные состояния
Добавить иллюстрацию (drip-символ) и одну тёплую строку + кнопку повтора,
вместо сухого текста. Ассеты уже есть.

### P7 — онбординг короче
3 экрана до списка ощущаются длинновато. Можно объединить «профиль + время»
или показывать прогресс яснее (сейчас точки — добавить подпись «шаг 3 из 6»).
