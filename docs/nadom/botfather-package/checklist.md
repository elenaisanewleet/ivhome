# @nadom_bot — Export & Launch Checklist

Пошаговый чеклист для запуска бота. Выполнять в порядке сверху вниз.

---

## 1 — Подготовка ассетов

| # | Задача | Файл | Статус |
|---|---|---|---|
| 1.1 | Открыть `assets/avatar.svg` в Chrome или Safari | avatar.svg | ☐ |
| 1.2 | Экспортировать как PNG 512×512 | avatar.png | ☐ |
| 1.3 | Открыть `assets/splash.svg` в браузере | splash.svg | ☐ |
| 1.4 | Экспортировать как PNG 320×600 (или 640×1200 @2x) | splash.png | ☐ |
| 1.5 | Открыть `assets/welcome-1280x720.svg` в браузере | welcome-1280x720.svg | ☐ |
| 1.6 | Экспортировать как PNG 1280×720 | welcome-1280x720.png | ☐ |

**Примечания по экспорту:**
- Для точного рендера шрифтов Unbounded + Onest браузер должен иметь доступ к Google Fonts (нужен интернет при открытии SVG).
- Альтернатива: открыть в Figma, встроить шрифты, затем экспортировать.
- Figma: File → Import → выбрать SVG → Export as PNG.
- Inkscape: File → Export PNG Image → установить ширину/высоту.

## 2 — BotFather Setup

| # | Команда | Действие | Статус |
|---|---|---|---|
| 2.1 | `/newbot` или `/mybots` | Создать или выбрать существующего бота | ☐ |
| 2.2 | `/setname` | Ввести: `Надом` | ☐ |
| 2.3 | `/setdescription` | Скопировать из `botfather-texts.md` → раздел /setdescription | ☐ |
| 2.4 | `/setabouttext` | Скопировать: `Агрегатор медицинских выездов на дом в Москве` | ☐ |
| 2.5 | `/setcommands` | Ввести: `start - начать` и `help - помощь` | ☐ |
| 2.6 | `/setprivacy` | Выбрать: `Enabled` | ☐ |
| 2.7 | `/setuserpic` | Загрузить: `avatar.png` (512×512) | ☐ |
| 2.8 | `/setdomain` | Ввести домен развёрнутого Mini App | ☐ |
| 2.9 | `/setmenubutton` | Тип: Web App, текст: `Надом`, URL: Mini App URL | ☐ |

---

## 3 — Переменные окружения

| Переменная | Значение | Статус |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather (из `/newbot` или `/mybots` → API Token) | ☐ |
| `TELEGRAM_WEBAPP_URL` | URL задеплоенного Mini App (Render / продакшн) | ☐ |

Не коммитить в репозиторий. Добавить в `.env` (gitignored) и в Render Environment Variables.

---

## 4 — Деплой бота

| # | Задача | Статус |
|---|---|---|
| 4.1 | Убедиться, что `TELEGRAM_BOT_TOKEN` задан в Render (или локально) | ☐ |
| 4.2 | Убедиться, что `TELEGRAM_WEBAPP_URL` задан и указывает на рабочий Mini App | ☐ |
| 4.3 | Задеплоить `apps/telegram-bot` | ☐ |
| 4.4 | Проверить лог: нет `"Telegram bot is disabled"` | ☐ |
| 4.5 | Написать `/start` боту в Telegram — убедиться, что приходит приветствие | ☐ |
| 4.6 | Нажать кнопку `подобрать вариант` — убедиться, что открывается Mini App | ☐ |

---

## 5 — Проверка ответов

| # | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| 5.1 | Написать `/start` | Приветствие + кнопка `подобрать вариант` | ☐ |
| 5.2 | Написать `/help` | Справка + кнопка `открыть Надом` | ☐ |
| 5.3 | Написать любое другое сообщение | Fallback + кнопка `открыть Надом` | ☐ |
| 5.4 | Нажать кнопку `подобрать вариант` | Mini App открывается | ☐ |
| 5.5 | Написать `/start` повторно | Та же реакция что и в 5.1 | ☐ |
| 5.6 | Отправить статус-уведомление через API | Сообщение приходит, кнопка работает | ☐ |

---

## 6 — Визуальная проверка

| # | Проверка | Статус |
|---|---|---|
| 6.1 | Аватар бота отображается в круге — символ виден чётко | ☐ |
| 6.2 | Имя `Надом` в заголовке чата | ☐ |
| 6.3 | Описание перед Start читается, не обрезается | ☐ |
| 6.4 | Кнопки `подобрать вариант` / `открыть Надом` по ширине чата | ☐ |
| 6.5 | Шрифт бота: сообщения выглядят как telegram-native (не рушит верстку) | ☐ |

---

## 7 — Приватность и безопасность

| # | Проверка | Статус |
|---|---|---|
| 7.1 | В логах бота нет адресов, телефонов, медицинских данных | ☐ |
| 7.2 | Токен `TELEGRAM_BOT_TOKEN` не в коде и не в коммитах | ☐ |
| 7.3 | Privacy mode бота: Enabled (проверить в BotFather → /mybots → Bot Settings → Group Privacy) | ☐ |
| 7.4 | Mini App валидирует `initData` на сервере | ☐ |
| 7.5 | В уведомлениях о статусе нет медицинских деталей | ☐ |
