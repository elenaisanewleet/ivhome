# Надом — голос

## Концепция: «тихий диспетчер»

Надом звучит как человек, который точно знает что делать и не тратит слов впустую.
Не система. Не ресепшен. Не чатбот.

Ближайшая аналогия: умный спокойный друг, который работает в медицине и отвечает в мессенджере.
Пишет коротко. Без "добро пожаловать". Без "ваш запрос принят в обработку".

---

## Миссия

> Показываем, кто приедет, когда и за сколько — вы выбираете медслужбу,
> остальное берём на себя.

Надом не лечит и не ставит диагнозы. Надом помогает быстро найти **медслужбу**,
которая приедет на дом, и показывает условия заранее: кто приедет, когда ответят,
когда приедут и сколько стоит. Детали и стоимость подтверждает выбранная медслужба.

Сила Надома — **прозрачность**: всё видно до заявки, без обзвона клиник.

---

## Три слова

**анонимно · быстро · удобно**

Это три обещания пользователю — и три фильтра для каждого текста.

- **Анонимно** — данные остаются в приложении, без лишних звонков и расспросов.
- **Быстро** — видно, когда ответят и когда приедут. Вместо долгих поисков.
- **Удобно** — выбор по району и времени в пару касаний, всё в Telegram.

### Теги-преимущества (для бейджей и списка фич)

| Тег | Смысл |
|---|---|
| **Приватность** | данные защищены, можно анонимно |
| **Гибкий поиск** | по району, времени, нужной помощи |
| **Удобная связь** | чат со специалистом прямо в приложении |

> Про слово «анонимно»: используем как **слово-преимущество** («анонимно · без лишних
> звонков»), но без абсолютных гарантий вроде «полностью анонимно, никто не узнает».
> В consent и правовых экранах — точные формулировки. Так слово работает на бренд
> и не создаёт юридического риска.

### Как звучит характер

Надом пишет как человек, который точно знает что делать и не тратит слов впустую.
Не система. Не ресепшен. Не чатбот. Спокойный, собранный, на стороне пользователя.

## Голос в разных ситуациях

### Приветствие
Без "Добро пожаловать!" Без "Привет! Я ваш помощник Надом!".
Просто появляется — как будто всегда был рядом.

```
привет 🫧

нужен выезд на дом — подберём вариант
```

### Информация о статусе
Факт + действие. Без эмоций. Без деталей в уведомлении.

```
заявка подтверждена · детали в приложении
```

### Ошибка / пауза
Не извиняться навязчиво. Объяснить одним предложением.

```
что-то пошло не так — попробуйте ещё раз
```

### 103 / 112
Спокойно и прямо. Без паники. Без "ВНИМАНИЕ!".

```
при таких симптомах лучше звонить 103 или 112
это быстрее, чем выезд на дом
```

## Правила

| ✓ Делаем | ✕ Не делаем |
|---|---|
| строчные там, где естественно | ВСЁБОЛЬШИМИ |
| короткие предложения | сложносочинённые конструкции |
| числа цифрами: "3 варианта" | "три варианта" |
| время: "~15 мин" | "приблизительно пятнадцать минут" |
| точка в конце — по смыслу | восклицательные знаки |
| нейтральный "я" только в /start | "я счастлив помочь вам" |
| "выбранная медслужба" | "наш партнёр" / "наш врач" |
| "детали подтверждает медслужба" | обещания результата |
| "анонимно" / "приватно" / "конфиденциально" | расплывчатые формулировки |
| "медслужба" (приоритет) | "наш партнёр", "служба" как замена |
| "когда ответят · когда приедут" | "SLA" / "ETA" (непонятно людям) |

## Уровни срочности — тон меняется

| Ситуация | Тон |
|---|---|
| Обычный запрос | Нейтральный, спокойный |
| Ожидание / пауза | Чуть теплее, без давления |
| Статус изменился | Краткий, информативный |
| Экстренные симптомы | Прямой, без паники, без "СРОЧНО" |

## Форматирование в Telegram

Telegram поддерживает HTML-теги. Используем экономно:

- `<b>bold</b>` — для ключевого факта в статусе
- `<i>italic</i>` — для дисклеймеров и уточнений
- Обычный текст — для всего остального

Никаких `<u>`, `<s>`, `<code>` в пользовательских сообщениях.
Только если это реально помогает воспринять информацию быстрее.

## Примеры правки

### Плохо → Хорошо

```
ДО:  Добро пожаловать! Я помогу вам найти подходящую медицинскую организацию
     для организации выезда специалиста к вам домой!

ПОСЛЕ: нужен выезд на дом — подберём вариант
```

```
ДО:  Ваш запрос успешно принят и направлен в выбранную вами медицинскую
     организацию для дальнейшей обработки.

ПОСЛЕ: взяли в работу
```

```
ДО:  К сожалению, в данный момент в выбранном вами районе отсутствуют
     доступные медицинские организации.

ПОСЛЕ: в этом районе сейчас нет вариантов · попробуйте другой район
```

```
ДО:  Специалист выбранной вами медицинской организации уже выехал
     к вам и прибудет в согласованное время!

ПОСЛЕ: специалист выехал
```

## Как говорить о времени (без «SLA» и «ETA»)

Пользователь не знает аббревиатур. Два разных времени называем по-человечески:

| Что это | Как пишем в UI | Чего избегаем |
|---|---|---|
| Время до ответа медслужбы | **ответ** · «ответят за ~15 мин» · «когда ответят» | «SLA ответа», «первичный отклик» |
| Время до приезда | **приезд** · «приедут за ~40 мин» · «когда приедут» | «ETA», «время прибытия по SLA» |

Пример карточки:

```
медслужба «Север»

ответят     ~15 мин
приедут     ~40 мин

от 3 500 ₽ · стоимость подтвердит медслужба
```

Коротко, два понятных слова: **ответят** и **приедут**. Никаких SLA/ETA.

## Терминология: что в приоритете

**Медслужба** — основной термин для поставщика услуги. По умолчанию всегда он.

Остальные слова разрешены и полезны там, где добавляют ясности или доверия:

| Слово | Когда уместно |
|---|---|
| **медслужба** | везде по умолчанию — главный термин |
| **проверенная медслужба** | когда нужно подчеркнуть доверие (тёплое, человечное) |
| **лицензия / лицензированная** | когда важна формальная проверенность — карточка, профиль, доверие |
| **медицинская организация** | формальные и правовые контексты, consent |
| **конфиденциально** | наравне с «анонимно» — про приватность данных |

Чего избегаем как замены для «медслужба»: **«партнёр»**, **«наш врач»**, **«служба»**.

Можно чередовать «проверенная» и «лицензированная» — оба работают на доверие.
Главное, чтобы существительным оставалась **медслужба**.

## Чего нет в Надоме

- Тревожности
- Медицинской иконографии (красные кресты, сирены, шприцы)
- Корпоративного "мы рады"
- Уменьшительных форм ("медсложечка", "вариантик")
- AI-флёра ("как ИИ-ассистент я...")
- Абсолютных обещаний ("гарантируем прибытие")
