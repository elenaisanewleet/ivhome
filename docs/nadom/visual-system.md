# Nadom visual system

## Source priority

For UI, frontend, and visual work, inspect the original references before changing visuals when they are available:

1. `docs/nadom/references/Выполнение промта по проекту - Claude.html`
2. `docs/nadom/references/saved_resource*.html`
3. `docs/nadom/references/visual/`

Use attached PNG visual references when they are available in the workspace. Continue the Claude HTML, saved-resource, and PNG visual style. Do not introduce a new generic SaaS style.

If older visual references contain wording that conflicts with `docs/nadom/public-wording.md`, the public wording rules override the older wording. Use old references for visual layout and style only.

## Core style

Use a soft pastel, Telegram-native visual language:

* main accent: `#7EB8D4`;
* light, calm backgrounds;
* soft blue and pastel-blue tones;
* rounded cards;
* calm rounded buttons;
* bubble or chat-style UI where relevant;
* minimal house, location, and point symbols.

## Avoid

Do not use:

* red crosses;
* sirens;
* aggressive warning blocks;
* hospital-noise visuals;
* bright green checkmarks as the main pattern;
* yellow smileys;
* generic AI or SaaS gradients;
* random palette changes;
* stethoscopes or doctors as the main brand image;
* medical clichés.

## Symbols and emoji

Use symbols sparingly and consistently:

* 🫧 for greeting and onboarding;
* 🪽 for visit, confirmation, or movement;
* 🩵 for support and final state;
* 🧊 for waiting and pause;
* ⋆ / ✦ / ⊹ for list markers.

Do not use emoji in hard-stop or legally sensitive messages.
